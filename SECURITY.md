# Security

Use GitHub's private vulnerability reporting for this repository when available:
https://github.com/Hovsteder/atum-sdk/security/advisories/new

If the private form is unavailable, open an issue asking for a private reporting
channel without including vulnerability details or secrets. Do not submit
credentials, owner data, tokens, proofs or production requests in a public issue.

This is a developer preview. Supported behavior and deployment boundaries are
listed in [release status](docs/status.md). Report the affected version, a minimal
synthetic reproduction, expected behavior and observed impact. Security fixes
must retain authorization, replay and original-operation recovery semantics.
